# 出力形式 (厳守)

出力は次の 7 つの見出しだけからなる Markdown とする。見出し文言・番号・順序を変えないこと。

## 論旨の流れ
- 問題: <この論文が取り組む問題を 1 文で> [根拠]
- 着想: <解決の鍵となる考え方を 1 文で> [根拠]
- 手法: <具体的な方法を 1 文で> [根拠]
- 結果: <主要な結果を 1 文で> [根拠]
- 意義: <この研究の意義を 1 文で> [根拠]
## 1. どんなもの？
## 2. 先行研究を比べてどこがすごい？
## 3. 技術や手法の肝はどこ？
## 4. どうやって有効だと検証した？
## 5. 議論はある？
## 6. 次に読むべき論文は？

## 文体
- 各項目の下は「- 」で始まる階層付き箇条書き (子項目は半角スペース 2 つでインデント)。
- **各箇条は主語と述語のある短い 1 文** とし、「。」で終える。体言止め・「→」「;」による列挙の連結・メモ書きはしない。
  - 悪い例: `- Hilbert 変換で phase/amplitude を分離 → adjoint source 導出`
  - 良い例: `- 本手法は Hilbert 変換で位相と振幅を分離し、それぞれの adjoint source を導出する。 [§2.2-p3]`
- 1〜6 の各項目は、論旨の流れと整合するように書き、項目間のつながりがわかるようにする。
- 一般用語以外は元の言語のまま表記する。数式は LaTeX ($...$)、数値は単位付きで論文の値をそのまま使う。
- 論文に書かれていないことを推測で補わない。不明な場合は「論文中に記載なし。」と書く。

## 根拠の表示
- **すべての箇条の文末に、根拠となる段落 ID を角括弧で付ける。** 例: `[§3.2-p4]`、複数なら `[§3.2-p4, §5.1-p2]`
- 段落 ID は「節ごとの読書メモ」に示された ID だけを使う。存在しない ID を作らない。
- 各項目は要点を絞って簡潔に書く (目安: 箇条 4〜7 個)。**文字数は数えないこと** (長さは別の工程で調整する)。

## 6. 次に読むべき論文は？ の書き方
- 各論文を `- 著者 (年) 「タイトル」: <その論文が何をしたかの要旨 (数語〜1 文)>。読むべき理由を 1 文で。 [根拠]` の形で書く。
- 根拠には、本文中でその論文を引用・言及している段落 ID を付ける。

- 前置き・後書き・コードブロックの囲みは出力しない。
